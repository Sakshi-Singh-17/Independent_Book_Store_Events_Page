# 📚 Independent Bookstore Events

A simple responsive web app for managing upcoming bookstore events.

The project allows the user to add new bookstore events, view them, and search. The events can be filtered by title, author or date. The project is built with HTML, CSS, and Vanilla JavaScript.

## ✨ Features

Add a new bookstore event

Enter event title, author, date, time, and an optional description

Display newly added events dynamically

Search events by:

Event title

Author

Date

Show an empty state when no matching events are available

Display a loading spinner during the loading process

Sanitize text input before storing event data

Responsive layout for desktop, tablet, and mobile devices

Accessible form labels and ARIA attributes

CSS based loading animation

Simple monochromatic blue UI

## 🛠️ Built With

HTML5 – Structure and semantic markup

CSS3 – Styling, responsive design, and animations

JavaScript (Vanilla JS) – Event handling, searching, validation, and dynamic DOM updates

Font Awesome – Icons used in the interface

The project does not use React, Bootstrap, Tailwind CSS, or any other frontend framework.
